# Site Carol Coelli | Psicóloga

Site estático (HTML + CSS + JS, sem dependências). Abra `index.html` no navegador ou rode `node .claude/serve.js` e acesse http://localhost:5173.

## Estrutura
- `index.html`, `sobre.html`, `servicos.html`, `produtos.html`, `blog.html`: as páginas
- `css/style.css`: visual e animações
- `js/main.js`: menu, rodapé, animações e **todos os links/contatos** (WhatsApp, Instagram, TikTok, e-mail, blog, loja) no topo do arquivo
- `img/`: imagens
